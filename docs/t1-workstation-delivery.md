## 用户主流程

导航仅今日、我的持仓、大盘行情、小道消息；候选与多 Agent 是辅助依据，历史量化验证留在离线和展开证据中。

## 验证边界

合成冷库用于可重复功能验收；不把它称为用户真实持仓。公网不录入虚假买卖或发送测试通知。
用户真实持仓、外发实际送达及首周噪音率需要对应真实运行证据，缺失时明确列为未完成。
L3 炸板不在 v1，显式标记未上线；不更改策略阈值或以 LLM 覆盖确定性评分。
