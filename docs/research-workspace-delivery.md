# 研究工作台完整交付

归属：`docs/architecture.md` §7.1。开始日期：2026-10-23。当前状态：D1–D3 实现、审查、合并、生产部署与公网验收完成。

## 产品目标

让使用者在一个连续流程内完成：查看今天研究状态 → 比较候选 → 追溯个股依据与风险 → 加入个人自选 → 回看跟踪。
交付标准是线上真实可用的任务流程和明显可见的页面重构，不以提示、文案或局部表单微调替代。

## 本轮范围

- 今日页：简洁页头、当日研究摘要、紧凑市场状态、候选工作区、按需展开的证据与复盘。
- 导航：桌面精简工作栏，手机保留主要任务入口和完整个人工具入口。
- 个股研究：同一日期的确定性评分、消息、讨论与风险线索；实时行情明确分开；自选与返回入口。
- 自选：已关注标的、行情、当天候选关联、继续研究和移除动作；保留既有浏览器私有存储。
- 原有行情、资讯、持仓、笔记与资料功能继续可访问；旧路由、深链接与日期选择兼容。

## 设计规范

- 研究终端风格：清晰分区、紧凑列表、数字对齐，以内容和状态组织界面，避免层层卡片。
- 延续 AQSP 品牌和涨红跌绿，保留深浅主题；背景和工作面使用中性灰，不再用装饰光晕。
- 首页先显示当日状态和候选，说明放到具体状态附近，长过程和历史资料按需展开。
- 桌面同时看到候选名称、评分、证据完整度和下一观察；手机采用纵向阅读和可触达的导航。
- 状态有文字及图标，不只依赖颜色；可交互项有可访问名称和键盘焦点，触控目标至少 40px。

## 数据与行为边界

- 领域判定复用 `daily-view` / `candidate-chain` / `decision-view`，页面不重算评分或放行规则。
- 历史日期和实时行情分开展示；历史页面不能把当日实时报价当作历史证据。
- 缺数据、读失败、门禁阻塞分别呈现；没有可信胜率时不编造统计，没有证据时不展示肯定结论。
- 自选继续使用现有 localStorage 键；不迁移用户持仓、不写生产样例数据、不引入新服务或重依赖。
- 异步请求切换标的时清理旧内容并忽略旧响应，失败保留已有个人记录并提供恢复入口。

## 交付批次

1. D1：今日工作台与导航。先做可使用的真实数据页面，经验证后阶段部署。
2. D2：个股研究与自选闭环。复用现有后端，补充必要归一化和针对性测试。
3. D3：全站入口回归、独立审查与最终线上验收，记录版本及实际运行证据。

## 验收标准

- 1440×1000 桌面首屏可识别当前研究日期、状态、候选名称及评分，不被入门说明和重复表格挤占。
- 390×844 手机无页面横向溢出，主要导航可用，候选与核心动作不需横向滚表。
- 从候选进入个股，看到同日依据，加入自选，回到自选继续研究；刷新后自选保留；支持移除。
- 日期切换后页面和深链接仍指向同一研究日期；无快照、未知股票、接口失败均可恢复，无旧股票数据残留。
- 类型、永久契约、构建、针对性和全量 Python 回归、secret 扫描、CI 和适用审查通过。
- 分批上线后用独立无头浏览器检查真实桌面/手机页面，核对线上 SHA；保留旧版本回退。
- 不将既有研究门禁失败或未产出的历史验证伪装为通过。
