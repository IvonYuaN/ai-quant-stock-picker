## 一、先纠正一个根本错误：11-13 的结论含前视

`industry_neutral_ic.py::_within_rank` 把 (T×N) 全矩阵 `ravel()` 后**只按行业码分组**
（`idx = flat_ind[m]`，无日期键），分母 `cnts[idx]` 是该行业**全期**有效观测数：

```
2 日 × 4 股同行业，values=[[1,2,3,4],[10,20,30,40]]
research 输出: [[0.125 0.25  0.375 0.5], [0.625 0.75 0.875 1.0]]   ← 8 个观测一起排
逐日横截面应: [[0.25  0.5  0.75  1.0], [0.25  0.5  0.75  1.0]]
```

⇒ `IN_val_pb_mrq` 不是「当日行业内分位」，而是 **PB 在该行业整个 3 年分布中的位置**：
2023 年某票的因子值取决于 2026 年的数据。`_group_mean`（所谓「行业内去均值」）
同样用 `bincount(idx)` 全期池化。

🔴 **作废**：`IC −0.071 / NW-t −3.35 / q 0.0026 / 联合正交后 t −3.02`，
以及 11-13 那轮所有「行业中性化后」的衍生结论（含 `val_pb_mrq 中性化 t −4.58`、
`fin_profit_accel 归零`、`lhb_appear_60d 二次被否`）—— 同源口径，须重算，不得引用。

> 这是「红线守卫是语法级（只查 `shift(-N)`/`rolling(center=True)`），对语义前视全盲」
> 的又一实证：本例没有任何语法级前视，是**分组键漏了日期**。

## 二、严格 PIT 重算：因子本体成立，但只有第一关

四口径对拍（`pb_pit_probe.py`，长表复现与原函数断言 `max|diff|=0` ⇒ 对拍有效），
**池内域**：

| 口径 | h=10 IC / t | h=20 IC / t | q(h=20) | 生产可实现 |
|---|---:|---:|---:|---|
| A 全期池化 lag0（research 原样，**含未来**） | −0.0521 / −2.93 | −0.0716 / −3.39 | 0.0015 | ❌ |
| B 逐日横截面 lag0 | −0.0406 / −2.75 | −0.0553 / −3.19 | 0.0023 | ⚠️ |
| **C 逐日横截面 + PB 滞后 1 交易日** | **−0.0400 / −2.71** | **−0.0553 / −3.19** | **0.0023** | ✅ |
| D 不做行业中性（PB 原值） | −0.0280 / −1.17 | −0.0421 / −1.45 | **0.154** | — |

- **A 精确复现旧结论** ⇒ 差异只来自「池化 vs 逐日」，不是数据或实现差异。
- **前视虚高 23% 的 IC**（−0.0716 → −0.0553）；滞后 1 交易日零损耗（双周频快照 + ffill）。
- **D 不显著** ⇒ 行业中性化是必要条件，判死现有 `ValueStrategy._calculate_pb_score`
  的绝对 PB 口径 `max(1-pb/5,0)`。
- 三层域 × 两 horizon **无符号翻转**，方向恒为「行业内越便宜 → 后续超额越高」。

⇒ **关 1（池内 IC）通过**：C 口径 h=20 IC −0.0553 / t −3.19 / q 0.0023。

## 五、判决

| 关 | 判据 | 结果 |
|---|---|---|
| 关 1 | 池内 IC 显著、三层无翻转 | ✅ 通过（−0.0553 / −3.19 / q 0.0023） |
| 关 2 | 联合正交后池内 \|t\|≥2 | ❌ **−1.89 / −1.95** |
| 关 3 | λ/top_n 敏感性改善显著 | ❌ **最大 t=+1.24** |

🔴 **判决：行业内 PB 不进生产打分，不投入完整 gate 轮（≈9.8h）。**

理由：
1. 按项目自身纪律「补因子先过池内 IC → 正交化 → λ/换手敏感性」，三关只过一关。
2. 完整 gate 轮要跑起来，还须先做三件工程（否则 gate **根本测不到 PB**）：
   - ①离线预计算分位列（`--skip-pit-financials` 下 frames 无 pe/pb）；
   - ②注入 streaming frames（按 batch 打分 ⇒ 策略内现算横截面会失真）；
   - ③新 grid 档位显式声明 7 维 `composite_weights`（变体默认清零全部权重）。
   在关 2/3 已塌的前提下投入这些工程 + 9.8h，是把负结论固化进生产，不是推进判决。
3. 改 `config/thresholds.yaml` 的策略阈值属红线（须附 walk-forward 验证报告），
   没有 gate 证据不得动。

## 七、顺带清掉 `invert_signal` 争议（同装置，零生产改动）

争议：yaml 两维均 `invert_signal: true`（#199 上线），历史实验判应 False，
卡在「须老大拍板」。用同一套作业面事件研究（`direction_probe.py`）对照 4 种方向：
A 双反向（当前 yaml）/ B 双正向（历史实验）/ C 反 mom+正 pvc / D 正 mom+反 pvc。

🔴 **必须先自查的口径坑**：`_pool_mask` 的「生产池」本身就是 **A 方向 top10%**
构造的 ⇒ 所有方向都在 A 偏好的票里选，会系统性压缩 B/D。故同时跑了
**全市场域**（`direction_probe_all.py`，pool 全 True）作对照。

| 方向 | 池内 h=20 Δ超额 | 全市场 h=20 超额 / t | 全市场 h=20 Δvs yaml / t |
|---|---:|---:|---:|
| A 双反向（**当前 yaml**） | 0（基准） | +0.0701% / +0.11 | 0（基准） |
| B 双正向（历史实验判应 False） | −0.3082% | −0.4766% / −0.36 | −0.5468% / −0.32 |
| C 反 mom + 正 pvc | −0.3116% | −1.0252% / −1.76 | −1.0953% / −1.62 |
| D 正 mom + 反 pvc | **+0.4069%** | **−4.1514% / −3.01** | **−4.2215% / −2.36** |

- **D 池内看着最好、全市场域却是显著最差**（h=10 亦 −2.6370% / t=−2.60）
  ⇒ 池内「优势」纯属**池构造假象**（在 A 选出的票里做反向 = 均值回归假象）。
  这类假象正是「按池内结果调参」的典型陷阱。
- **B（历史实验主张）在两域、两 horizon 都不优于 A**，h=10 全市场 −1.0459% / t=−1.00。
- A 是四者中全市场域唯一接近 0 的（h=10 −0.1207%、h=20 +0.0701%）。

⇒ **结论：翻转 `invert_signal` 缺乏证据，当前 yaml 双反向不应改。**
⚠️ 口径限制：这里用 research 侧 `mom_20`/`pv_corr_20`，与生产
`MomentumStrategy`/`PriceVolumeLevelCorrelation` 打分实现不同源；
本组证据只判**方向**、不判幅度，**不能替代 gate（判红权威）**。
但足以把「历史实验判应 False」这个待拍板项从「无判据」推进到「有明确反面证据」。
