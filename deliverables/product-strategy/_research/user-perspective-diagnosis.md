# AQSP 实盘用户视角诊断（瑞思）

> 日期：2026-07-08 ｜ 输入：老大实盘反馈逐字记录 + 代码现状核实（backend/portfolio.py、HoldingsPage/WatchlistPage/ConceptsPage/InfoStreamPage、src/aqsp/risk/）

## TL;DR（3 行）
1. 老大的优先级是「小道消息 + 选股 + 大盘」三件套，围绕 **T+1 实盘买卖决策**服务；当前系统的每日候选不稳定、无"我操作了什么"输入通道、无"该卖了"提醒，主 loop 三个环节全断。
2. 大量投入（DSR/PBO 门禁、CSCV 多变体回测、7 维权重调优、三层风控）服务于"系统证明自己"，用户**从不消费**这些输出，属于"纯粹为了做而作"。
3. 砍掉板块页、合并持仓+自选、补齐"操作回录 + 卖出提醒"两个通道，系统就从"看着玩的仪表盘"变成"实盘副驾驶"。

## 用户核心 Loop（从用户视角重画）

```
┌─ 每日盘前/盘中 ─────────────────────────────────────────────┐
│ ① 看小道消息（InfoStream：12赛道108源）  ← 用户最看重 ✓     │
│ ② 看大盘行情（指数/情绪）                       ✓ 有        │
│ ③ 看持仓+自选（合并视角，一眼判断）          ✗ 两个页面     │
│ ④ 看今日候选（选股结果）→ 决定买不买          ⚠ 每日重刷    │
├─ 交易软件侧（通达信等）────────────────────────────────────┤
│ ⑤ 实盘买入/卖出，系统不介入（用户明确说不需要系统交易）      │
├─ 回来喂系统 ────────────────────────────────────────────────┤
│ ⑥ 输入"我买/卖了什么" → 系统记住 → 强化分析跟进  ✗ 无通道   │
│ ⑦ 需要卖的时候系统主动提醒我                      ✗ 无提醒   │
└──────────────────────────────────────────────────────────────┘
```

**断点**：③（持仓/自选分裂 + 板块页干扰）、④（候选日变，信任无法建立）、⑥（无操作回录）、⑦（止损/止盈模块只跑在回测里，`stop_loss.py`/`unified_risk.py` 对实盘持仓零产出——`portfolio.py` 里只有 add/remove/close + 浮盈亏展示，没有一条"该卖了"的告警路径）。

## 痛点清单（按优先级）

| # | 痛感 | 用户故事（T+1 实盘交易者） | 现状 | 断在哪 | 严重度 |
|---|------|--------------------------|------|--------|--------|
| P0 | 每日候选全换，早中晚看的是不同批次 | 作为 T+1 交易者，我想要今日候选盘前锁定、盘中只增量修正，以便我开盘前就能定好买卖计划 | 每日多批刷新生成，"早中午进去都是一批新的内容" | 候选无当日快照/冻结机制，与 T+1 决策窗口（收盘前决策、次日执行）错位 | 高（直接摧毁信任） |
| P0 | 操作完了没有入口告诉系统 | 作为实盘用户，我买/卖完想一键回录（代码+方向+价格+数量），以便系统后续帮我盯这只票、强化分析 | `portfolio.py` 有 `add_holding`/`close_position` 数据结构，但 UI 上没有对应的"今天我操作了"轻入口，回录路径不顺手 | 输入通道缺失/不显眼 | 高（loop ⑥ 断） |
| P0 | 该卖没人提醒 | 作为持仓者，我设定止损/止盈条件后，盘中触发了系统就该主动提醒我，以便 T+1 内及时处理 | `stop_loss.py`（单票/组合/移动止损）、`unified_risk.py`（三层风控）逻辑齐全但只用于回测；`portfolio.py` 无告警产出 | 风控引擎与实盘持仓完全脱钩 | 高（loop ⑦ 断） |
| P1 | 板块页冗余 | 作为用户，我只要"持仓+自选"一个合并页，不必再逛一个板块维度 | `ConceptsPage.tsx` 独立成页 | 用户明言"板块太多余了，持仓自选合并以后就够了" | 中（信息噪音） |
| P1 | 持仓和自选是两页 | 作为用户，我想在一屏看到"我持有的 + 我关注的"，快速对照 | `HoldingsPage.tsx` 与 `WatchlistPage.tsx` 独立页面 | 缺少合并视图 | 中 |
| P2 | 系统展示了我不看的量化指标 | 作为用户，我只关心"买不买、卖不卖"的结论，不关心 DSR/PBO 门禁、CSCV 多变体回测、7 维权重这些过程数字 | 这些模块大量存在且在前端有展示 | 输出与用户消费点错位 | 中（信任稀释） |

## "为自己做"清单（用户不消费的功能）

| 模块 | 用户是否看 | 判断依据 | 建议 |
|------|-----------|---------|------|
| DSR / PBO 统计门禁 | 否 | 老大反馈无任何提及；实盘用户只消费"买/卖建议+理由" | 降级为后台质检日志，退出主界面 |
| CSCV 多变体回测 | 否 | 回测是研发信心工具，非用户决策输入 | 保留离线跑，结果只影响策略上线与否，不展示 |
| 7 维权重调优 | 否 | 用户不消费权重数字；他要的是"选出来能稳定复用" | 调优结果固化为快照，冻结期内参数不变（顺带解决 P0-1） |
| `unified_risk.py` 三层风控（回测态） | 部分 | 逻辑有价值，但当前形态是回测组件 | **复用**而非删除：把单票/组合止损阈值接到实盘持仓上产生盘中提醒（P0-3），风控就"活了" |
| 板块页（ConceptsPage） | 否 | 用户明言多余 | 降为持仓页内的辅助标签，或折叠进自选页 |
| 12 赛道 108 源消息流（InfoStream） | **是** | 用户优先级第一位（"合理的小道消息"） | 保留并置顶；"合理性"指要做降噪/可信度分层，而非砍掉 |

## 非目标（不该做什么）
- **不做实盘交易通道**（用户有通达信等交易软件，明确说"其他你又不能实盘交易，我有交易软件，还用这个系统干嘛"）。
- 不追求候选池"越多越好"——每日给出**少而稳、可执行**的结论。
- 不在主界面堆量化指标、回测报表、门禁数字。
- 不新增用户不消费的独立页面（板块、回测中心、指标面板）。
- 不替用户下"必须买/必须卖"的最终决定——系统给信号和提醒，用户自己决策并回录。

## 建议（按 ROI 排序）
1. **候选冻结机制**：盘前生成当日候选快照并冻结，盘中只做"新增/失效"增量标注；T+1 决策窗口内结果稳定。
2. **操作回录轻入口**：全局一条"我操作了 [代码/方向/价格/数量]"录入，写进 `portfolio.py`（add_holding/close_position 已具备），触发系统对该票进入"强化盯盘"状态。
3. **卖出提醒**：把 `stop_loss`/`unified_risk` 的阈值逻辑挂到实盘持仓上，触发软止损/硬止损/止盈时产生显式提醒（站内/推送），T+1 可行动。
4. **页面合并**：持仓+自选合并为一页；板块页降级或并入；首页聚焦"消息 → 大盘 → 持仓 → 候选 → 买/卖结论"的用户 loop 顺序。
5. **指标降噪**：DSR/PBO/权重调优等移入"研发/质检"区域，日常界面隐藏。

## 给用户的一句话
**"这个系统应该像副驾驶：你报单、它盯盘、到点喊你——不是像仪表盘：塞满你看不懂的指针。"**
