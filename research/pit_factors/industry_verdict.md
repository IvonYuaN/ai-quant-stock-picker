## 一、为什么要做这一轮

上一轮结论是「基本面/估值维度基本证伪」。但那个检验有一个**没说出口的前提**：全部用**跨行业**截面比较。

PE / PB / ROE / 净利同比都是**强行业属性**（银行 PE≈5 vs 半导体 PE≈60），
跨行业排序等于把"属于哪个行业"当成信号。**行业内排序**才是可交易的比较口径。

同时这一轮还充当**对前两轮结论的稳健性拷问**：把已检验的 81 个因子做行业中性化后重算 IC，
如果某个因子的预测力全部来自行业暴露，它会当场归零。

## 三、结果

### 3.1 行业中性化让多个因子的信号**质变**（池内 h=20）

| 因子 | 中性化前 t | 中性化后 t | q |
|---|---:|---:|---|
| `lhb_appear_60d` | −4.49 | **−6.03** | 5.7e-08 |
| `logvol_20` | −3.92 | −5.17 | 4.5e-06 |
| `val_pb_mrq` | **−1.43** | **−4.58** | **5.7e-05** |
| `max_ret_20` | −2.36 | −4.36 | 1.3e-04 |
| `val_mcap_log` | −2.57 | −2.57 | 0.023 |

⇒ 跨行业口径**稀释**了大量因子的真实信号；`val_pb_mrq` 从"无效"变成"显著"。

### 3.2 唯一通过全部判据的候选：**行业内 PB（相对便宜度）**

`IN_val_pb_mrq` = 行业内 PB_MRQ 分位（每只票在**同行业**内的 PB 排名）

| 判据 | h=10 | h=20 |
|---|---|---|
| 全市场 t_nw | −3.80 | −3.60 |
| 可交易域 t_nw | −3.36 | −3.14 |
| **生产池 t_nw** | **−3.07** | **−3.35** |
| 符号翻转 | 无 | 无 |
| BH-FDR q（池内） | 0.0058 | **0.0026** |
| 正交后（对自身孪生 + 生产 2f）t | −3.15 | −3.45 |
| **联合正交**（logvol+turnover+amihud+idio_vol+市值+生产2f） | — | **−3.02**（IC −0.071→−0.043）|

**相关性**（池内截面中位）：与市值 +0.11、与 logvol −0.04、与 turnover −0.04、与 amihud −0.09、
与 idio_vol +0.35、与动量 −0.21、与 ROE +0.07、与净利同比 +0.15
⇒ 81 个因子里**只有 1 个 ρ≥0.5**（它自己的"去均值版"孪生，ρ=0.80），与生产 2f ρ≤0.21。

**方向明确**：行业内 PB 越低（越便宜）→ 后续 h 日超额越高（IC 为负，因子值是"便宜度"）。

**为什么它是"新增量"而不是重复**：生产打分器的 `value` 子分**已 `enabled: false`、权重 0.0**，
估值维度在生产上**完全没有启用** ⇒ PB 是空着的那一格。

### 3.3 被否的候选（诚实记录）

| 候选 | 否掉的理由 |
|---|---|
| `lhb_appear_60d/20d`（龙虎榜热度） | 正交后 IC −0.069→**−0.017**，t −6.03→**−1.32** ⇒ 仍是波动/流动性因子的代理（**第二次被否**） |
| `IN_val_mcap_log`（行业内市值） | 与 `IN_amihud_20` **ρ=−0.794**（小市值=高流动性 ⇒ 流动性族代理）；且**可交易域 t≈0**（+0.20/−0.39）⇒ 三层链不成立 |
| `IN_val_pe_ttm`（行业内 PE） | 池内 t −2.06/−2.44，q 0.075/0.032 ⇒ 边缘，且与 PB 同族（ρ=0.42） |
| `IN_fin_roe` | 符号翻转（h=10）；t≈0 |
| `IN_fin_profit_yoy` / `IN_fin_profit_accel` | 池内 t 0.99/1.96 ⇒ 弱 |

## 四、🔴 对上一轮结论的自我修正

上一轮判定「**唯一活下来的弱候选 = `fin_profit_accel`（净利同比加速度）**」。
本轮加行业中性化后：**该因子的行业中性化版 IC 直接归零**
（h=10 IC=+0.003 t=+0.33；h=20 IC=−0.000 t=−0.04），正交后还翻成 t=−2.19/−2.84。

⇒ **`fin_profit_accel` 的微弱信号来自行业 beta（某些行业的财报改善更集中），不是选股 alpha** ⇒ 上一轮结论**作废**。

⇒ 修正后的结论：**目前唯一站得住的新因子是行业内 PB**。
