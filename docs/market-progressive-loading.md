# 市场数据渐进呈现

对应 architecture.md §7.2 D1。指数、外围、宽度/资金、情绪、成交额榜和行业榜独立读取；任何一项返回立即显示，不等待其它慢源。

- `market-load.ts` 分别发布 `pending`、`failed` 与已返回载荷；成功空数据不记为请求失败，读取中也不宣称证据缺失。
- `useMarketData` 每轮使用独立 `AbortController` 和序号。刷新与卸载取消旧请求；即使加载器忽略取消，旧回包也不能覆盖新轮数据。
- 市场页在读取中仍可重新读取；首页先显示已取得的市场/行业证据，余项用一行读取状态呈现。
- 每轮清空旧载荷，避免将不同轮次拼成同一行情；保留各源原始时间，不用取数时间替代行情时点。

`market-load.test.ts` 用可控异步请求验证快源先出现、慢源未结束、单项失败与成功空值区分、快照稳定、实际取消和迟到回包隔离。
